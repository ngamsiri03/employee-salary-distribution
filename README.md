# Employee Salary Distribution

## 📊 Project Overview

This project visualizes the distribution of employee salaries using a bar chart.

The purpose of this visualization is to show how many employees belong to each salary range.

## 📁 Dataset

The dataset contains two columns:

- `salary_range` - Employee salary range
- `count` - Number of employees in each salary range

## 🧹 Data Cleaning

The dataset was checked before visualization.

The following checks were performed:

- Missing values
- Duplicate records
- Invalid salary ranges
- Invalid count values
- Data type consistency

No missing values, duplicate records, or invalid values were found.

Therefore, the dataset can be used directly for visualization.

## 📈 Visualization

The visualization shows:

| Salary Range | Employees |
|--------------|-----------|
| 20k-30k | 10 |
| 30k-40k | 15 |
| 40k-50k | 20 |
| 50k-60k | 12 |
| 60k-70k | 8 |

## 🔎 Key Finding

There are 65 employees in total.

The 40k-50k salary range has the highest number of employees, with 20 employees.

The 60k-70k salary range has the lowest number of employees, with 8 employees.
